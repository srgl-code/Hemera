Requisitos de Banco de Dados

Estrutura de dados do Hemera — tabelas, relacionamentos e scripts SQL desenvolvidos por Erivan Junior para a Sprint Review 2.

DDL

Definição de Estrutura
  • tb_usuarios — perfis, biometria vocal
  • tb_dispositivos — IoT, sensores, atuadores
  • tb_eventos — log de comandos e automações
  • tb_rotinas — schedules e regras automáticas
  • tb_configuracoes — preferências por usuário
  • RLS — Row Level Security por morador

DML

Manipulação de Dados
  • INSERT de usuários (Mariana, Rafael e moradores padrão)
  • INSERT de dispositivos IoT (luzes, sensores, climatização)
  • INSERT de rotinas automáticas (despertar, encerramento)
  • INSERT de eventos históricos para testes de DQL
  • Scripts de seed para ambiente de desenvolvimento

DQL — 9 Categorias

Consultas & Relatórios
  1. 01.Histórico de comandos por usuário
  2. 02.Consumo energético por dispositivo
  3. 03.Rotinas mais ativadas por morador
  4. 04.Dispositivos com mais falhas/timeouts
  5. 05.Agenda de compromissos por dia
  6. 06.Padrões de comportamento por horário
  7. 07.Relatório de produtividade semanal
  8. 08.Status atual de todos os dispositivos
  9. 09.Ranking de uso de comandos de voz
